# Sales-Analysis-and-Forecasting
Developed a Python-based application for sales forecasting and trend analysis, integrating a user-friendly GUI with Tkinter for broad accessibility. Implemented data visualization using libraries like Pandas, Numpy and some ML models like Linear Regression, ARIMA to predict future sales trends based on historical data.

This is not the complete version of my project, some update are to be done for gui and prediction models.
